## ✨ 核心亮点

- **可编辑图层**：文字、图片、贴纸、纸张均可独立编辑，不用重抽
- **中文排版优化**：手写体 + 纸张纹理 + 贴纸，一键出图
- **长文自动拆分**：一段文字 → 一套完整小红书图文（3–5 页）
- **丰富素材库**：20+ 手写字体 · 34+ 纸张纹理 · 160+ 素材贴纸
- **支持格式**：小红书图文（3:4 / 1080×1440）、A4 等
- **导出 PNG**：一键导出，编辑不扣费

## 🚀 三步出图

1. **描述需求**  
   把要写的文字 / 想要的风格丢给 AI。

2. **AI 生成图文卡片**  
   自动排好手写体 + 纸张 + 贴纸版式。

3. **微调 · 导出**  
   换字、挪贴纸、换纸张，不重抽，一键导出 PNG。

## 🆚 和普通 AI 出图的区别

| 对比项 | 普通 AI | 文卡网 |
|--------|---------|--------|
| 输出形式 | 一张整图 | 可编辑图层 |
| 修改文字 | 需要重新生成 | 直接双击编辑 |
| 素材调整 | 不可独立编辑 | 图片 / 贴纸 / 纸张均可独立调整 |
| 内容到排版 | 分步处理 | 同一画布完成 |

## ❓ 常见问题

**文卡网和普通 AI 文生图有什么区别？**  
普通 AI 输出的是一张整图，文字难以单独调整；文卡网输出可编辑图层，文字、版式、贴纸、纸张均可独立修改。

**能免费做小红书图文吗？**  
可以。注册赠送 10 积分，生成消耗积分，编辑和导出免费。一套图文通常 2–3 积分。

**生成的图文可以编辑吗？**  
可以。双击文字即可修改，也可通过图层列表搜索编辑。贴纸和纸张同样支持独立调整。

**做一套小红书图文要多久？**  
内容准备好后，通常 2–3 分钟生成。

**积分是怎么计算的？**  
按模型 Token 消耗计费。上下文越长、模型越强，消耗越多。建议新建项目以节省积分。
